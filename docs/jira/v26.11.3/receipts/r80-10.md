## Defects found and fixed in-session

1. **Stated-digest form bug (mine)**: `admission_digest` returned bare hex
   while `valid_digest`/SHACL demand `sha256:<64 hex>` — every honest stamp
   failed recomputation as DigestMismatch. Found by the admit/verify round
   trip test failing 9/20; root-caused via an instrumented example run (bare
   hex vs prefixed form divergence); fixed by returning the prefixed form.
   Debug artifacts removed.
2. **Borrow/unused warnings**: `pins()` stored `&str` borrows of a
   loop-local; switched to owned Strings. Unused binding in `apply_pins`
   fixed.
