## Charter

Close TX-11's structural finding: `SovereignLease` and `EpochPlan` (E80-9) were
landed but UNCOMPOSED with the execute loop — nothing carried an admitted lease
into a decision. This lane composes them: when `ExecuteOpts` carries an admitted
lease + epoch watermark, each order's plan emission is admitted ONLY IF the
lease binds the order and the epoch watermark proves freshness; refusal is
typed (`LeaseNotBound` / `EpochStale`) and leaves state unmutated.
