# Generated surface authority

Generated artifacts are projections, not independent authority. The v26.8.1 corpus must record for every generated file:

- canonical ontology, manifest, template, or generator source;
- production command that regenerates it;
- ownership header and generated/manual merge boundaries;
- expected deterministic hash or semantic equivalence rule;
- verifier that detects hand edits, stale output, missing output, or divergent regeneration;
- legacy recovery path.

A file located in a constitutional or documentation directory does not become authoritative merely by location. Provenance and active load path determine authority. Generated and receipt surfaces must remain distinct: output bytes establish the projection; receipts establish provenance and execution evidence.
