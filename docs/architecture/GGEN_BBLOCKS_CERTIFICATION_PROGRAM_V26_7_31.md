# ggen Building Blocks Certification Program v26.7.31

## Preserve

The certification program qualifies a person or agent to reconstruct governed capability from canonical ggen Building Blocks.

Every credential level uses the same executable case study:

```text
TAI-REBUILD-001
```

The case is not an illustrative paragraph. It is the ontology-authored pack and generated consumer under:

```text
packs/tai-enterprise-rebuild-pack
examples/tai-enterprise-rebuild
```

The programme preserves the TAI enterprise-rebuild fence:

1. **Technology Applications, Inc.** is the historical systems-of-systems observation.
2. **Automated Technical Capability Company** is the modern target enterprise.
3. **Target Architecture Instance** is the exact versioned graph object reconstructed by the candidate.

These objects are related but not equivalent. Historical performance does not establish current standing. A target description is not an admitted instance. An admitted instance is not `ALIVE` without execution evidence.

## Constitutional law

```text
O → O* → μ → A → R
```

- `O` — partial observations: historical TAI, mission, standards, constraints, evidence, and outcomes.
- `O*` — the admitted enterprise graph with bounded identity, authority, closure, and exclusions.
- `μ` — lawful ggen manufacturing and dependency-closed transition planning.
- `A` — the reconstructed enterprise capability.
- `R` — observed consequence, receipt, and deterministic replay.

BRCE is the only lawful future external actuation address. The certification kernel is deterministic and IO-free. It assesses evidence and reconstruction receipts; it cannot deploy, award contracts, issue external credentials, or operate production systems.

## Certification calculus

Each requirement is complete only when the receipt binds the same candidate, requirement, and `TAI-REBUILD-001` identity and contains:

```text
positive witness
+ negative falsifier
+ independent verifier
+ receipt verifier
+ deterministic replay
```

The manufactured artifact is also bound into the receipt as the object tested by those five surfaces.

A level is cumulative:

```text
Award(candidate, level, TAI-REBUILD-001)
iff
for every requirement q where q.level <= level:
  complete(q.evidence)
```

The first crown contains:

```text
12 requirements × 5 proof surfaces = 60 certification proof surfaces
```

An external badge is a projection of an award receipt. It cannot self-promote capability standing.

## Credentials

### GBB-100 — TAI Foundation

The candidate must preserve the three-object TAI fence and diagnose malformed enterprise blocks.

Required outcomes:

- distinguish observation, target enterprise, and exact target instance;
- explain identity, lifecycle, standing, ports, ceilings, obligations, exclusions, provenance, and authority;
- map malformed Mission, Contract, Capability, Certification, Organization, Technology, Quality, Evidence, and Economics blocks to stable refusals and bounded repairs.

Material falsifiers include certificate-implies-standing, missing passports, missing dependencies, invalid ports, missing falsifiers, and detached provenance.

### GBB-200 — TAI Builder

The candidate manufactures one passport-bound TAI Building Block.

The block must include typed ports, executable contract, resource and authority ceilings, exclusions, provenance, selected realization, lifecycle obligations, and complete five-surface evidence.

`ALIVE` is mechanically derived. It cannot be asserted from source presence or lifecycle state.

### GBB-300 — TAI Composer

The candidate composes dependency closure and emits a replay-stable BLAKE3 composition receipt.

The candidate must refuse:

- duplicate identities;
- missing dependencies;
- dependency cycles;
- incomplete enterprise closure;
- incompatible profiles;
- silent deletion of mission, quality, evidence, lifecycle, or broker constraints.

The implementation sequence is generated from graph state. It is not maintained as an independent schedule.

### GBB-400 — TAI Governor

The candidate governs substitution and concept-through-decommission lifecycle.

A substitution is lawful only when it preserves promised ports, passport standing, authority ceilings, resource ceilings, supportability, replacement, and retirement boundaries.

Lifecycle, evidence standing, and BRCE-addressed intents remain orthogonal.

### GBB-500 — TAI Manufacturer

The candidate executes the full `TAI-REBUILD-001` case.

Required outcomes:

1. generate unresolved lifecycle, realization, evidence, profile, and dependency work from current graph state;
2. manufacture the consumer twice and prove byte identity;
3. execute historical, rebuilt-today, post-AGI, delayed-contract, unavailable-certification, failed-inspection, and founder-unavailable scenarios;
4. verify BLAKE3 artifact receipts;
5. refuse unknown scenarios and tampered artifacts;
6. replay exactly;
7. recover a declared failure without bypassing admission, verification, BRCE, receipt, or replay;
8. manufacture a verifier and falsifier another candidate can run independently.

The pure certification kernel emits only unresolved work:

|---|---|

A TAI rebuild receipt is unreachable while one roadmap step remains.

## Exclusions

The bounded certification does not establish:

- that historical TAI has been recreated;
- that an operating company exists;
- that a contract exists or was awarded;
- issuer-recognized certification standing;
- production, field, laboratory, customer, or cloud operation;
- psychometric validity outside the declared fixtures;
- arbitrary enterprise safety;
- permission to commit generated outputs by hand;
- permission for cognition to authorize its own I/O.
