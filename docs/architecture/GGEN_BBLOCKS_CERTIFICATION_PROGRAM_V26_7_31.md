# ggen Building Blocks Certification Program v26.7.31

## Preserve

The certification qualifies a person or agent to reconstruct governed capability from canonical ggen Building Blocks.

Every credential uses the same executable case and standards boundary:

```text
case study: TAI-REBUILD-001
standards:  GGEN-STANDARDS-7D-2026-07-30
```

The case is the ontology-authored pack and executable consumer under:

```text
packs/tai-enterprise-rebuild-pack
examples/tai-enterprise-rebuild
```

The programme preserves three distinct TAI objects:

1. **Technology Applications, Inc.** — historical systems-of-systems observation.
2. **Automated Technical Capability Company** — modern target enterprise.
3. **Target Architecture Instance** — exact versioned graph reconstructed by the candidate.

Historical performance does not establish current standing. A target description is not an admitted instance. An admitted instance is not `ALIVE` without execution evidence. A pending standard is not an admitted capability.

## Fence

Every award is bound to:

- the candidate identity;
- the exact certification requirement;
- `TAI-REBUILD-001`;
- the exact seven-day standards-profile identity;
- the canonical BLAKE3 digest of that profile;
- positive witness;
- negative falsifier;
- independent verifier;
- receipt verifier;
- deterministic replay;
- the artifact those surfaces verified.

Evidence from another case, another standards version, another candidate, or another requirement is refused.

## Constitutional law

```text
A = μ(O*)
R = receipt(A)
```

The operation rail is:

```text
O → O* → I → G → A → R → O′
```

- `O` — partial observation;
- `O*` — admitted, aligned, complete, grounded, and bounded observation;
- `I` — deterministic intent;
- `G` — exact execution grant;
- `A` — bounded consequence;
- `R` — causal receipt;
- `O′` — independently re-observed postcondition.

```text
candidate != verified != authorized != actuated
planning != actuation
cognition != authority
```

BRCE is the only lawful external `DO` address. The certification kernel is deterministic and IO-free. It cannot deploy, issue external credentials, award contracts, or operate production systems.

## Exclusions

The bounded certification does not establish:

- that historical TAI has been recreated;
- that an operating company or contract exists;
- issuer-recognized credential standing;
- production, field, laboratory, customer, or cloud operation;
- universal psychometric validity;
- arbitrary enterprise safety;
- permission to hand-edit generated outputs;
