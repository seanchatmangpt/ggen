# CertificationAssist Evidence Control v26.7.31

## Decision

Real learner efficacy, psychometric validity, and external issuer standing are not manual review notes. They are governed feedback-control systems.

The system automatically admits and evaluates evidence. It autonomically manufactures bounded corrective intents. It may mechanically update standing when—and only when—the relevant authority and evidence policy are satisfied.

## Three control loops

### Learner efficacy

```text
baseline
→ intervention
→ post-assessment
→ delayed retention
→ transfer task
→ efficacy standing
```

The learner loop computes basis-point learning gain, retention, and transfer. Sparse evidence remains `COLLECTING`. Failed thresholds create remediation, spacing, and transfer-practice intents.

### Psychometric validity

```text
item responses
→ sample and exposure checks
→ difficulty
→ discrimination
→ calibration standing
```

Small samples cannot self-validate. Weak items create quarantine and form-rebalance intents. The system never silently rewrites item evidence.

### External issuer standing

```text
issuer trust anchor
→ authenticated credential/status evidence
→ monotonic status synchronization
→ active/suspended/revoked/expired standing
```

External standing is automatic but never locally invented. Issuer status is authoritative. Autonomics can request refresh, renewal, review, or reacquisition, but cannot purchase, schedule, renew, or award a credential.

## Constitutional rule

```text
automatic != self-awarded
autonomic != unbounded
```

Automatic means the evidence path executes without repeated manual bookkeeping.

Autonomic means the controller detects drift and manufactures the next bounded action.

Neither means that synthetic evidence can impersonate a learner, a psychometric population, or an issuer.
