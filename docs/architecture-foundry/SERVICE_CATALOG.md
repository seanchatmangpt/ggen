# Enterprise Architecture Reconstitution and Manufacture — Service Catalog

## Category definition

Enterprise Architecture Reconstitution and Manufacture converts an existing software estate into executable architecture knowledge, then uses that knowledge to manufacture new solution architectures with independent evidence, receipts, and replay.

The service does not sell a rewrite. It sells the conversion of undocumented software history into reusable production capital.

## Platform

**ggen Enterprise Architecture Foundry**

Tagline:

> Reconstitute proven architectures. Manufacture the next enterprise system.

## Service 1 — Repository Observation

### Purpose

Perform a non-mutating, evidence-bound assessment of a repository or repository estate.

### Activities

- exact-head baseline;
- repository and Git-history observation;
- capability extraction;
- architecture and organizational constraint discovery;
- generated-surface and configuration analysis;
- verification-gap analysis;
- drift, ambiguity, and orphan detection;
- preliminary kernel-versus-corpus classification.

### Deliverables

- Repository Archaeology Graph;
- Capability Inventory;
- Architecture Constraint Map;
- Unknown and Ambiguity Ledger;
- Verification Coverage Report;
- Reconstitution Work Program;
- observation receipts.

### Completion standing

`OBSERVED`

This service does not assert migration completeness or retirement safety.

## Service 2 — Architecture Corpus Formation

- disposition analysis;
- cross-repository extraction;
- provenance preservation;
- architecture decision reconstruction;
- primitive generalization;
- positive and negative evidence creation;
- corpus ontology and verifier construction.

### Deliverables

- admitted capability graph;
- Legacy Capability Ledger;
- cross-repository lineage portfolio;
- architecture primitive catalog;
- reference witnesses;
- negative fixtures;
- corpus receipts;
- corpus standing report.

## Commercial differentiation

Traditional consulting primarily delivers documents and human recommendations.

The foundry delivers:

- executable semantic authority;
- reusable architecture primitives;
- manufactured repositories;
- independently computed standing;
- cryptographic lineage;
- deterministic replay;
- explicit refusal and recovery behavior.

The customer does not merely receive an architecture diagram. The customer receives a system that can re-manufacture the architecture and prove what was produced.
