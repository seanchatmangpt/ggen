# phd-thesis-template

PhD thesis template with chapters, appendices, TOC/LOF/LOT, and customizable university requirements

## Overview
The `phd-thesis-template` package provides comprehensive tools, templates, and ontologies for code generation and semantic modeling using ggen.

## Features
- Fully integrated with ggen marketplace
- Production ready templates and schema definitions
- Standardized metadata and automated validation

## Quick Start
```bash
ggen marketplace search "phd-thesis-template"
ggen marketplace install "phd-thesis-template"
```
