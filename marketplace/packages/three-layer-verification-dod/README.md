# three-layer-verification-dod

Full three-layer DoD: OTEL span proof + test assertion + weaver schema conformance. For production projects requiring complete evidence-based verification.

## Overview
The `three-layer-verification-dod` package provides comprehensive tools, templates, and ontologies for code generation and semantic modeling using ggen.

## Features
- Fully integrated with ggen marketplace
- Production ready templates and schema definitions
- Standardized metadata and automated validation

## Quick Start
```bash
ggen marketplace search "three-layer-verification-dod"
ggen marketplace install "three-layer-verification-dod"
```
