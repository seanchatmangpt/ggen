# 33. GGEN-EA-100 to CROWN: Self-Hosting

## GGEN-EA-100 - ArchiMate and Stakeholder Views

Generate capability, value-stream, application, technology, migration, risk, and evidence views from the canonical graph. Export ArchiMate as a projection, not the authority.

## GGEN-EA-110 - Portfolio and Economics

Connect capability leverage, cost, risk, consumer adoption, support, and lifecycle. Generate investment and retirement recommendations with disclosed measures.

## GGEN-EA-120 - Architecture Pack Factory

Use ggen to manufacture architecture packs, transition packs, conformance packs, and organization overlays from admitted architecture knowledge.

## GGEN-EA-130 - Self-Hosting

The architecture model generates:

- its own mdBook;
- `SUMMARY.md`;
- metamodel documentation;
- CLI;
- validation;
- roadmap;
- Gall checkpoints;
- CI;
- capacity suites;
- release policy;
- receipts.

## GGEN-EA-CROWN - Executable Enterprise Architecture

Crown claim:

> A material change to any admitted ecosystem object can be traced through affected capabilities, products, ontologies, packs, projections, requirements, owners, consumers, work packages, operating consequences, validation obligations, and migration paths before actuation.

Required evidence:

- real repository integration;
- at least one external consumer;
- positive transition;
- refused transition;
- rollback;
- capacity result;
- runtime observation;
- replay across a clean environment.

The crown is not achieved by generating the architecture book. The book becomes one projection and one acceptance surface of the system it describes.
