# pcq-marketplace-pack

Projects an admitted PCQ capability marketplace into a canonical Next.js 16 + deck.gl application. The ontology owns currency supply, accounts, market nodes, listings, settlement policy, streaming policy, and dependency versions. Gates refuse incomplete authority, invalid PCQ economics, dangling references, duplicate identities, unsafe coordinates, and unbounded streaming.

PCQ is a governed internal unit of account. The pack does not claim fiat, legal-tender, securities, or external-exchange standing.
