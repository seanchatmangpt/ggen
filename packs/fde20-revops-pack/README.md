# fde20-revops-pack

Ontology-first ggen pack for the **$20/hr FDE RevOps** operating model.

It manufactures three projections from one RDF authority graph:

- `revops/fde20/OPERATING_CONTRACT.md` — economic, authority, and standing contract.
- `revops/fde20/CHALLENGER_MOTION.md` — teach/reframe/new-way/proof/take-control commercial motion.
- `revops/fde20/pipeline.json` — machine-readable SELECT → CONSTRUCT → DO revenue pipeline.

Admission gates refuse drift away from USD 20/hour, non-deterministic operating semantics, malformed stage topology, skipped stage edges, and any DO path that is not BRCE + receipt bounded.

The pack does **not** actuate CRM, email, billing, deployment, or customer systems. It manufactures the admitted operating graph and deterministic projections that downstream gdmcp/AutoFDE/BRCE adapters may execute through their own authority boundaries.
