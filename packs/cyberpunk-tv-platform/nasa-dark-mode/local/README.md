# NASA Dark Mode No-CI Execution Capsule

This authored rail executes every boundary reachable in the local container without using GitHub Actions as evidence.

```bash
./local/run-no-ci.sh
```

It performs deterministic manufacture, Roku package replay, a clang-manufactured WebAssembly state core, exhaustive JavaScript/WASM equivalence, headed Chromium WebGL2 execution under Xvfb/ANGLE SwiftShader, strict source-derived BrightScript simulation, dependency/toolchain probes, mutation controls, and one aggregate receipt.

The rail does not claim that its BrightScript simulator is a physical Roku. It also does not replace deck.gl with a look-alike library: the exact deck.gl runtime remains typed `BLOCKED_DEPENDENCY_TRANSPORT` when its pinned package body cannot be admitted locally.
