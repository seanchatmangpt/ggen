# ggen Enterprise GitHub Repository Architecture

GENERATED by `ggen sync` from `packs/gh-enterprise-architecture-pack/ontology.ttl`.

## Law-state pipeline

```text
GitHub corpus O
  -> immutable source observations
  -> admission / exclusion / UNKNOWN
  -> canonical enterprise profile O*
  -> generated Terraform A = μ(O*)
  -> plan and explicit approval
  -> apply through an authorized actuation path
  -> GitHub re-observation
  -> receipt and replay hook
```

The source corpus is evidence, not authority. An observed block cannot enter the
factory until its repository, commit, path, blob, license boundary, and admission
decision are present. `UNKNOWN` never upgrades to admitted state.

## Composition

`gh-terraform-pack` remains the institutional desired-state layer for one
repository. `gh-enterprise-architecture-pack` adds the reusable multi-repository
factory and the corpus-admission control plane. The committed example composes
both packs without overlapping generated paths.

The enterprise module manufactures:

- `github_repository` instances from a typed repository map;
- optional main-branch protection with admitted required checks;
- flattened per-repository labels;
- flattened per-repository milestones;
- stable repository identity outputs.

## Preserved exclusions

- No GitHub mutation occurs during corpus discovery.
- No observed HCL is promoted mechanically.
- `github_issue` remains a line-event command, not desired state.
- `github_repository_file` is excluded because ggen owns generated file content.
- Provider upgrade is outside this change; the admitted source and existing pack
  remain pinned to `integrations/github` `5.41.0`.
- Secret values never enter ontology or committed Terraform input.

## Falsifier

Delete `ghea:sourceBlob` from either admitted corpus observation and run sync.
The corpus gate must refuse generation. Change a source commit or blob without a
new admission decision and the generated architecture has no standing.

## Ten Gall checkpoints

1. **Corpus transport** — enumerate every accessible repository or classify the edge `UNKNOWN`.
2. **Immutable provenance** — bind each admitted source to repository, commit, path, and blob.
3. **Admission** — refuse incomplete admitted observations through SPARQL.
4. **Authority fencing** — exclude issues and repository files from Terraform ownership.
5. **Ontology unit** — parse the graph and require zero gate rows.
6. **Generation integration** — sync a clean consumer through the real engine.
7. **Artifact inspection** — assert repository, protection, label, milestone, and output surfaces.
8. **Boundary sabotage** — remove an admitted blob and require refusal.
9. **Replay** — run a second sync and require byte identity.
10. **Acceptance** — run Terraform validation and repository-level CI in an authorized environment.

A checkpoint is not promoted to `ALIVE` without observed execution evidence.
